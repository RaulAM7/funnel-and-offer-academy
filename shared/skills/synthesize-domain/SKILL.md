---

# Goal
Elevate knowledge from source-bound book level to domain-wide synthesis and internal method.

# Inputs
- All `book-synthesis.md` files within the domain's author(s) folders
- Existing `cross-work-synthesis.md` (if updating)
- Existing `internal-method/` files (if updating)

# Outputs
- `04_outputs/academy/[domain]/[author]/cross-work-synthesis/cross-work-synthesis.md`
- `04_outputs/academy/[domain]/[author]/internal-method/method-draft.md` (optional, when patterns are strong enough)

# Procedure

1. Read all book synthesis documents for the domain.
2. Identify:
   - Common principles across books (convergence)
   - Complementary frameworks (each book adds something different)
   - Contradictions or tensions between authors/books
   - Patterns that no single book states but emerge from the cross-reference
3. Write the cross-work synthesis:
   - Convergence section (what all/most books agree on)
   - Complementarity section (where each book fills a different gap)
   - Tension section (contradictions, with analysis of when each applies)
   - Emergent patterns section (what the cross-reference reveals)
4. If patterns are strong enough, draft internal method additions:
   - Only include items with high confidence from multiple sources
   - Mark everything as draft
   - Trace provenance to source books
5. Write all user-facing content in Spanish; keep framework names in original English.

# Anti-patterns
- Running this with only one book synthesized. Minimum two.
- Forcing convergence where genuine tension exists.
- Producing method entries without provenance tracing.
- Making the internal method too abstract to be actionable.
